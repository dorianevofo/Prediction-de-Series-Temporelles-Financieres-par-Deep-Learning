# Prediction-de-Series-Temporelles-Financieres-par-Deep-Learning
Modélisation et prédiction des cours boursiers de l'action Apple (AAPL) à partir d'historiques de marché structurés en fenêtres glissantes.

Évaluation comparative entre réseaux récurrents simples (RNN) et LSTM: RNN Classique/RNN avec mécanisme d'attention, puis LSTM Classique/LSTM avec mécanisme d'attention
